## 项目背景

这是一个语言统计小实验，目标是回答一个简单的问题：

> **英文中，哪 3 个连续字母出现的频率最高？**

思路很直接——把足够多的英文文本喂给程序，让它老老实实地数数。选取了 **100 份英文原版书籍** 作为语料库，覆盖面广、样本量大，统计结果更有说服力。

## 统计方法

| 步骤 | 说明 |
|---|---|
| 1. 读取 | 逐行读取 `books/` 目录下所有 `.txt` 文件 |
| 2. 清洗 | 用正则 `[^a-zA-Z]` 去除空格、标点、数字等非字母字符 |
| 3. 归一化 | 统一转换为小写，避免 `The` 和 `the` 被当成不同结果 |
| 4. 切片统计 | 在**每一行内部**滑动窗口取长度为 3 的子串，累加计数 |
| 5. 排序输出 | 按出现次数从高到低排序，输出频率最高的组合 |

> ⚠️ **注意**：统计只在同一行内进行，不会跨行拼接字母（例如某行结尾的 `th` 不会和下一行开头的 `e` 拼成 `the`），这样可以避免因为换行符处理不当带来的统计误差。

运行后会先打印正在读取的文件列表，再输出出现频率最高的组合排行榜。

## 核心算法

统计逻辑的核心只有几行代码——对每一行清洗后的字符串做滑动窗口切片：

```java
String pure = line.replaceAll("[^a-zA-Z]", "").toLowerCase();
for (int i = 0; i <= pure.length() - 3; i++) {
    String tri = pure.substring(i, i + 3);
    countMap.put(tri, countMap.getOrDefault(tri, 0) + 1);
}
```

例如字符串 `"hello"` 会被切分为 `hel`、`ell`、`llo` 三个 trigram，各自计数 +1。最后用 `HashMap<String, Integer>` 汇总全部书籍的统计结果，再转为列表按次数排序：

```java
list.sort((o1, o2) -> {
    int cmp = Integer.compare(o2.getValue(), o1.getValue());
    return cmp != 0 ? cmp : o1.getKey().compareTo(o2.getKey());
});
```

次数相同时按字母顺序排序，保证结果**可复现、无歧义**。

## 统计结果

基于 100 份书籍语料，出现频率最高的前 5 个三字母组合：

| 排名 | 组合 | 出现次数 |
|:---:|:---:|---:|
| 🥇 1 | `the` | 756,013 |
| 🥈 2 | `and` | 358,347 |
| 🥉 3 | `ing` | 274,839 |
| 4 | `her` | 204,116 |
| 5 | `tha` | 168,246 |

## 结果分析

- **`the`** 遥遥领先，这与它是英语中使用频率最高的单词（定冠词）完全吻合，几乎每句话都会用到。
- **`and`** 作为最常用的连词，几乎在任何篇幅的英文文本中都会大量出现。
- **`ing`** 主要来自现在分词 / 动名词（`doing`、`thinking`、`morning` 等），是英语中最典型的构词后缀之一。
- **`her`**、**`tha`** 分别来自 *her/there/other* 和 *the/that/than* 等高频词的内部片段，说明高频 trigram 往往是高频单词的"副产品"。

整体结果与已有的英文字母/词频研究基本一致，说明统计方法是可靠、有效的。
